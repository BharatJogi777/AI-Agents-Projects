# Foundations (AG-001–AG-050)

This track builds reliable agent primitives: model adapters, typed tool execution, context management, memory, explicit state, retries, budgets, cancellation, security boundaries, observability, and application interfaces.

Projects use Python 3.12+. Run `python -m pytest` from each project directory. AG-050 additionally requires FastAPI, Pydantic v2, and httpx. Implementations remain in progress until local verification.
