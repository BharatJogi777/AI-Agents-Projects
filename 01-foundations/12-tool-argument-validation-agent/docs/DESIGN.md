# Design notes — AG-012

## Threat model

The gate receives tool names and arguments generated by an LLM. Both are untrusted. The gate's responsibility is to ensure that only known handlers receive validated, bounded, JSON-compatible input. It is not a sandbox and does not make a handler safe.

## Validation order

The tool name is checked first so unknown calls cannot trigger parsing work. String payloads are UTF-8 byte-bounded before JSON decoding. JSON decoding rejects duplicate keys and non-standard constants. Parsed or directly supplied values must be a dictionary and must survive strict JSON serialization. Finally, the selected Pydantic model validates the payload in strict mode.

The argument model should normally set `ConfigDict(extra="forbid", strict=True)`. The gate uses strict validation even if a model's configuration is less strict, but extra-field rejection is explicitly controlled by the model configuration.

## Feedback design

Validation feedback contains only bounded field paths and Pydantic error type identifiers. It deliberately excludes rejected input values and Pydantic message strings, because those can echo secrets or attacker-controlled content. A caller can send this compact feedback to a model for a repair attempt, but retry count and total prompt budget belong to the agent loop.

## Handler boundary

Only validated arguments reach the handler. Handler exceptions are wrapped in `ToolHandlerFailed`; the original cause is chained for protected diagnostics but its message is not exposed by the public error. Handler output is serialized with NaN/Infinity disallowed, bounded by UTF-8 bytes, and decoded again to detach mutable objects and guarantee JSON compatibility.

## Limits and non-goals

`GateLimits` configures maximum input bytes, output bytes, and validation feedback entries. This package does not implement user authorization, tenant isolation, network restrictions, process sandboxing, timeouts, cancellation, rate limits, idempotency, or durable audit. Add those controls at the execution runtime and handler boundary.
